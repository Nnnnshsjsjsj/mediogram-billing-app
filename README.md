# Mediogram Billing

**App: https://nnnnshsjsjsj.github.io/mediogram-billing-app/**

This repository only hosts the built web app. It contains no study data, prices, names or bank details. All data lives in Mediogram's Supabase database, and each account can read only what its role allows: doctors and sponsor clinical reviewers never receive amounts. The source code is kept in a private repository.

Sign in with the login and password Mediogram gave you (for example `nazar`).
